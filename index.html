📥 GitHub 업로드용 `questions.json` 내려받기

현재 앱에 적용된 단어·문법·문장 데이터를 `questions.json` 파일로 저장하여 GitHub 저장소에 바로 올릴 수 있습니다.

📂 내 기기에서 `.json` 문제 파일 바로 열기

GitHub에 올리기 전이거나 오프라인일 때, 태블릿/PC에 있는 JSON 문제 파일을 직접 선택해 즉시 적용합니다.

✨ 단어와 예문만 적으면 5가지 영역 문제가 자동으로 만들어집니다!

🚀 일정관리표처럼 GitHub Pages로 매주 문제 갱신하는 법

  1. 최초 1회 업로드: GitHub에 새 저장소(예: english-workbook)를 만들고, 이 앱 파일 이름을 index.html로 바꾼 뒤 questions.json 파일과 함께 업로드합니다.
  2. GitHub Pages 활성화: 저장소의 Settings → Pages → Branch (main) Save를 누르면 https://아이디.github.io/english-workbook/ 주소가 생성됩니다.
  3. 갤럭시탭 홈 화면에 등록: 갤럭시탭 삼성 인터넷이나 크롬에서 위 주소를 열고 [홈 화면에 추가]를 해둡니다.
  4. 매주 문제 갱신하기:
    • 이 창 상단의 [2️⃣ 간편 주간 단어 입력] 탭에서 이번 주 단어를 넣고 [questions.json으로 저장]을 누릅니다.
    • GitHub 저장소에 해당 questions.json 파일만 덮어쓰기(Commit)하면, 갤럭시탭에서 앱을 열 때 자동으로 새 주차 문제가 반영됩니다!

📘 초등 4학년 핵심 문법 노트

문제를 풀기 전 핵심 규칙을 터치해서 확인해 보세요.

1. be동사 (am / are / is)

• I am (~이다/있다)
• You / We / They are
• He / She / It / 단수명사 is

2. 현재진행형 (be동사 + ~ing)

• '지금 ~하고 있는 중이다'를 뜻해요.
• 예: She is reading a book.

3. 위치 전치사 (in / on / under)

• in (~안에), on (~위에), under (~아래에)
• Where is the bag? It's under the desk.

4. 조동사 Can & 일반동사 3인칭

• can + 동사원형 (~할 수 있다)
• 주어가 He/She/It일 때 일반동사 뒤에 -s/-es!
